# EcoImpacto

**Pequenas atitudes. Grandes impactos.**

Site acadêmico da disciplina de Front-End — UNICID, 2026.

## Executar localmente
- Abra `index.html` no navegador; ou execute `npm start` com Node.js e acesse `http://localhost:3000`.
- A página inicial fica na raiz do repositório.

## Páginas principais
Início, Sobre, Projetos, Impacto, Acessibilidade, Galeria, Mídia, Notícias, Contato e Orçamento.

## Recursos
HTML semântico, CSS responsivo, menu móvel, formulário demonstrativo com validação no navegador, ajuste de fonte, galeria e servidor Node básico.

Os indicadores são demonstrativos. O formulário não envia nem armazena dados em servidor. O áudio depende de arquivo local e o iframe de vídeo precisa receber o ID escolhido pela equipe.

## Deploy na Railway
Build: Nixpacks. Start command: `npm start`. O projeto usa `server.js` e escuta a variável `PORT` fornecida pela plataforma.

## Repositório
A versão anterior está preservada na pasta `Versão final ll/`. A implementação funcional mais recente está na raiz para facilitar a detecção de `index.html` pelo serviço de hospedagem.
