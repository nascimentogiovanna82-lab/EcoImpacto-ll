ACESSO PARA TODAS AS PESSOAS

Acessibilidade é essencial

O EcoImpacto busca oferecer uma experiência clara, inclusiva e utilizável por diferentes pessoas.

Recursos disponíveis

  • Navegação por teclado e foco visível.
  • Textos alternativos em imagens informativas.
  • Contraste e tipografia pensados para leitura.
  • Estrutura semântica e idioma português do Brasil.
  • Controles para aumentar ou diminuir o tamanho do texto.

Preferências de leitura

Use os controles para ajustar o tamanho do texto nesta página e nas demais páginas do site.

Atalhos úteis

Use a tecla Tab para avançar entre links e controles, Shift + Tab para voltar e Enter para ativar o item selecionado. O link “Pular para o conteúdo” aparece ao navegar pelo teclado.

Compromisso contínuo

Os recursos técnicos são parte do processo. Testes com pessoas com deficiência e melhorias contínuas são importantes para avaliar a experiência real.
